第1条（収集する情報）

当運営者は、本サービスの円滑な提供およびユーザー利便性の向上のため、以下の情報を適法かつ公正な手段によって取得します。

1. アカウント登録および認証情報：

氏名またはニックネーム、メールアドレス、暗号化（ハッシュ化）されたパスワード、WebAuthn/パスキー認証に伴う公開鍵情報。

2. 外部連携アカウント（Google OAuth等）から取得する情報：

利用者が外部サービス連携ログインを選択した場合に当該事業者の認可画面を通じて提供される一意のユーザーID、メールアドレス、プロフィール名、およびアイコン画像URL。

3. サービス利用ログおよび端末情報：

アクセス日時、IPアドレス、ブラウザ種別、OS情報、リクエストURL、Cookie情報、ならびに各ツールの実行履歴（模擬面接履歴、入力テキスト等）。

第2条（情報の利用目的）

取得した個人情報は、以下の目的の範囲内でのみ利用し、法令の定めがある場合を除き、利用者の事前の同意なく目的外の利用は行いません。

  • 本サービスの提供、ユーザー認証、本人確認、およびアカウントの維持管理
  • 各ツールにおける利用履歴・セッションデータの保存、復元、および個別分析フィードバックの提供
  • システムの障害対応、不正アクセス・サイバー攻撃の検知およびセキュリティ対策
  • 重要なお知らせ、規約変更等の事務連絡、およびユーザーからのお問い合わせ対応
  • サービスの利用動向の把握、利便性向上、および機能改善のための統計的分析

第3条（Googleユーザーデータの取扱いおよび限定使用の遵守）

本サービスが Google OAuth API を通じて受信した利用者の情報（以下「Googleユーザーデータ」）の利用および他アプリへの移転は、「Google API サービスのユーザーデータに関するポリシー（限定使用要件を含む）」に厳格に準拠します。

  • Googleユーザーデータは、本サービスにおける本人認証およびアカウント連携の目的のみに使用します。
  • Googleユーザーデータを広告の配信、ターゲット広告の作成、またはデータブローカー等への販売・譲渡に利用することは一切ありません。
  • Googleユーザーデータおよび利用者の入力コンテンツを、当運営者または第三者の機械学習・AIモデルのトレーニング（教師データ）として利用・提供することはありません。

第4条（個人情報の第三者提供の制限）

当運営者は、次に掲げる場合を除くほか、あらかじめ利用者の同意を得ないで個人情報を第三者に提供しません。

  • 法令に基づく開示請求がなされた場合
  • 人の生命、身体または財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき
  • 公衆衛生の向上または児童の健全な育成の推進のために特に必要がある場合
  • 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合
  • 利用目的の達成に必要な範囲内において、サーバーインフラ提供事業者や外部クラウド事業者等にシステムの保守・運用を委託する場合（この場合、適切な監督を行います）

第5条（安全管理措置）

当運営者は、利用者の個人情報の漏洩、滅失または毀損の防止その他の安全管理のために、以下の物理的・技術的措置を講じています。

  • 通信の暗号化： 全ての通信に SSL/TLS 暗号化通信を採用し、第三者による盗聴・改ざんを防止しています。
  • パスワードの不可逆暗号化： パスワードは最新のハッシュアルゴリズム（Argon2id/bcrypt等）を用いてソルト付きハッシュ化を施し、平文での保管を行いません。
  • アクセス権限の最小化： サーバー環境およびデータベースへのアクセスは多要素認証と厳格な権限分離により制限しています。

第6条（Cookieおよびセッション技術の利用）
